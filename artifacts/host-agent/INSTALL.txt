================================================================
  DecentralHub — Агент хостинга (Windows)
  Версия: 1.x  |  Требования: Windows 10/11, Node.js 20+
================================================================

БЫСТРЫЙ СТАРТ
─────────────
1. Распакуй ZIP в любую папку, например:
       C:\CloudAgent\

2. Дважды кликни  start.bat
   При первом запуске скрипт установит зависимости Node (~2 мин).
   Окно агента откроется автоматически.

3. Вставь токен хоста
   Токен берётся в веб-дашборде: Хостить → скопировать токен.
   Вставь в поле «Токен хоста» и нажми Сохранить.

4. Выбери игру и нажми «Выйти в онлайн»
   Агент зарегистрирует сессию. В веб-дашборде появится
   «Агент онлайн ✓» с временем последнего сигнала.

5. Отправь игроку ссылку (автоматически копируется)
   Игрок открывает ссылку в браузере и сразу видит стрим.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ — ЧЕКЛИСТ
────────────────────────────────────
□ Node.js 20 или новее установлен?
      node --version   → должно быть v20.x.x или выше
      Скачать: https://nodejs.org/en/download

□ Агент запущен от имени администратора?
      Некоторые игры с античитом (EAC, BE) требуют прав админа.
      ПКМ по start.bat → «Запустить от имени администратора».

□ Файрвол или антивирус не блокирует порт 18080?
      Агент слушает  http://localhost:18080
      Добавь исключение для node.exe в настройках файрвола.
      Windows Defender: Параметры → Защита от вирусов → Добавить исключение.

□ Ошибка «koffi не загрузился» или нет управления мышью/клавиатурой?
      Пересобери нативные модули: запусти rebuild.bat (или в папке агента
      выполни:  npm rebuild --build-from-source ).
      Нужны Visual C++ Build Tools (устанавливаются вместе с Node.js).

□ Окно игры не захватывается автоматически?
      Агент покажет список всех открытых окон — выбери нужное вручную.
      Убедись, что игра запущена ДО нажатия «Выйти в онлайн».

□ Агент запускается, но сайт не показывает «Агент онлайн»?
      Проверь, что платформа открыта по правильному адресу.
      Попробуй открыть в браузере:  http://localhost:18080/ping
      Должно вернуть:  {"ok":true,"version":"..."}

□ Ничего из выше не помогло?
      Нажми «Открыть агент» на дашборде → вкладка «Лог» — скопируй
      последние 20 строк и отправь в поддержку.


ПОРТЫ, КОТОРЫЕ ИСПОЛЬЗУЕТ АГЕНТ
────────────────────────────────
  18080  —  локальный HTTP (ping, input-injection)
  Входящих портов не нужно — соединение с игроком идёт через WebRTC
  (STUN/TURN), никаких проброс портов роутера не требуется.


УДАЛЕНИЕ
────────
Просто удали папку с агентом. Никаких записей в реестре.
